Make yourself at home

Appearance and existing navigation preferences are saved in this browser. Academic text is not stored for offline use.

Install on Android

  1. Open ANVAYA in Chrome on your Android phone using a trusted secure connection.
  2. Open the browser menu and choose Add to Home screen → Install when available.
  3. Open ANVAYA from your home screen. Keep the Python host running for academic work.

Installation depends on your browser and secure connection.

Installing this interface does not install Python on your phone. Plain Wi-Fi HTTP and public serving are not supported by private mode. This prototype accepts loopback connections only; authenticated encrypted cross-device access needs a separate validated setup.
