# Reusable ChatGPT authoring brief

Prepare a source-grounded ANVAYA Learning Studio package using the supplied actual import schema and coverage contract. Inputs: original PDF bytes; registry source ID; SHA-256; page count; current read-only course/topic catalogue, if available. Missing source identity must remain a blocker for a production import; use a labelled synthetic disposable ID only for a demo. Do not invent registration or mapping.

Preserve the original and every page extract/preview. Produce stable lesson IDs, complete full notes and exact citations. Keep original claims, classroom shorthand, added explanations and disputed/attributed material visibly distinct. Preserve every bullet/list member, comparison, table, equation and diagram relationship; inspect visuals, then record a coverage ledger with page/locator evidence and unresolved reasons. Mechanical coverage is not semantic or external factual certification.

Include source-linked revision notes and revealable recall cards, concept comparisons, memory traps and a final checklist. Quick revision is a labelled subset with a link to full coverage. Author at least useful action/feedback/source interactions only using the documented trusted widget contract. Do not insert HTML/SVG/code, remote URLs, callbacks or executable content.

Provide low-stakes MCQs with stable IDs/revisions, distinct choices, private zero-based correct indices, explanations and precise supporting pages. Independently check every key and whether each question is answerable from its cited lesson/source. Public projections must exclude MCQ keys/explanations before answering. Reflection/reveal/retry is not mastery or an official grade.

Keep fidelity-review, external fact/quotation review and academic mapping independent. Report only genuinely unresolved intent/attribution/mapping items with snippets and proposed explanations; never mark all pages verified to finish. Publish a new immutable derived revision when changing content, preserving historical attempts and source bytes.

Return a canonical bundle plus companion coverage where supported, a compact unresolved queue, and the exact preflight command. Run the strict executable preflight before claiming import compatibility. If unavailable, mark NOT RUN. Never correct a source mismatch by rewriting an expected checksum. No production academic writes or public redistribution of private lecture content.
