# ANVAYA 1.4.0 Library 2.0 release contract

This document describes the candidate, not a certification that it has passed.
The workflow appends actual exact-source run links only after successful gates.

Android Library opens semester/subject folders, retains originals unchanged,
uses read-only native viewer grants, and processes supported text locally through
one leased queue into the canonical Tutor index. Queue work resumes when the
app opens; no closed-app completion or OS scheduling is claimed. Existing
explicit indexing opt-outs are preserved. The sixth subject is unspecified;
only configured authoritative subjects appear.

Native schema 2 is additive and retains document/folder IDs. Before a v1 store
is changed, a verified snapshot is retained. Legacy canonical PDF sources keep
their IDs and logical paths through a verified managed-original adapter. Study
history, Notes and Studio identities are not reset. Uncertain files remain
Unsorted; no filename-based subject guesses are applied.

Backup v2 streams to disk and supports v1 import, hashes/sizes, safe restore
staging and recoverable atomic replacement. Limits: 4 GiB expanded collection,
512 MiB individual file, 20,000 entries; it is unencrypted. Existing unavailable
originals are explicitly declared and remain recovery records after restore.
Unexpected missing promised bytes are rejected. Free space is required for
snapshots, archive verification and restore. Old versions must not open schema 2.

Local extraction: embedded PDF text, PPTX slide order, UTF-8 text lines and
bounded DOCX paragraphs. PPT/DOC and images are stored only. Scans have no OCR
unless an actual optional local engine is installed and separately verified.
Code files are passive text. No hidden downloads or external AI requests occur.

Required publication gates: exact-head and merged-main canonical Ubuntu/Windows;
same candidate APK installed on API31/API35; source/tree, SHA256, version/code,
ABI and certificate provenance; downloaded published bytes equal tested bytes.
Physical Galaxy M11, real vendor viewer applications and production signing
remain unavailable unless explicitly supported by new evidence. Debug runner
keys may differ from an installed app. A signature mismatch must never be solved
by uninstalling or clearing existing study data. Verify a backup first.
