# Notes and Knowledge acceptance

My Notes remains the independent personal JSON/assets library. Its source disclosure explains the separate Obsidian vault, and filtered-empty and unavailable states no longer claim the student has no notes. Typed/handwritten labels, existing card styles and note identity remain intact. Mobile filters share two columns; the first populated fixture card moved from about 964px in the first redesign to about 730px after independent critique. The desktop library stays two-column.

Personal and vault readers have comfortable measure, secondary key-point/source disclosures and explicit editor navigation. The legacy vault reader now has one main landmark. Editors retain exact payloads, expected versions, media actions and explicit save boundaries; no auto-save is claimed. Native Notes focus and keyboard Study Tools work without replacing the existing handlers.

Knowledge is source-first: query and results, native filter disclosure (open for active filters), clear snippets, linked source titles, source/version-aware Ask action, original links and a readable passage view. Diagnostics remain available in secondary disclosures. Landing/empty/degraded states offer honest recovery; no new confidence percentage or retrieval ranking is invented.

Proof includes native Notes filtering → reader → editor with identity/content intact; source search → original reader; native no-JavaScript search/navigation; escaped source titles; unchanged version fields; and fingerprints of vault Markdown, Obsidian SQLite, personal Notes JSON and Resources JSON for read-only no-JavaScript visits. Related legacy source/editor/security route suites are retained. No note migration, unification, retrieval rebuild or academic-evidence promotion occurs.
