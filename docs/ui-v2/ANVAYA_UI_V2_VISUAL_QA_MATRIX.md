Read UX_REVIEW.md for the independent seven-surface, eight-axis before→after scoring and evidence boundaries. Read ENGINEERING_REVIEW.md for reproducible findings and closure. All Critical/Important findings identified by those reviewers are closed; minor limits are listed explicitly rather than converted into inflated global scores.

Residual limits: OS multilingual glyph availability in Linux captures; small metadata text; mobile Knowledge header/tool density; narrow table scroll cues; the Notes first card is earlier than the rejected redesign but later than baseline. No automated axe package was available in the pinned environment; semantic/keyboard/code review and real-browser checks were performed, without claiming complete WCAG certification.

Reproducible rough server-render timing and HTML/CSS/JS byte measurements are in performance.json, generated by scripts/ui_v2_metrics.py. These are warmed fixture request medians, not network/browser performance or a claim of speedup. New scoped assets increase opted-in page weight; protected pages do not load them.
