# Learning Studio V1 import contract

Canonical schema: `anvaya.learning-module.v1`. Machine-readable structural schema: `docs/learning_studio/learning-module-v1.schema.json`. Authoritative semantic/security validator: `personal_learning_assistant/learning_studio/validation.py`. Proposed pilot JSON is deliberately not accepted as canonical JSON without conversion.

Packages contain immutable module_id/module_revision, title/unit, a source record, optional reviewed mapping, every ordered page identity, ordered sections with structured blocks, separate revision blocks and stable versioned low-stakes MCQs. source_id refers to an existing Knowledge document. The source loader reads its registry metadata and logical-root original file without writes. Source PDF bytes, hash and page count must agree. Each section/block/question has nonempty valid page references.

Original source authority remains Knowledge/Resource. The derived store keeps an immutable byte snapshot and raster evidence per module revision so old lesson references remain accessible after an original changes. This snapshot cannot be edited and never registers/replaces a production source. A source change requires a new module revision; failed integrity never publishes. Page semantic fidelity states are authored review assertions (`verified`, `needs_review`, `unavailable`), distinct from byte/page validation. No automated semantic certificate is issued.

Mapping is null by default. A non-null mapping must provide a current registered course_id, EXACT canonical topic_name, reviewed=true and confidence >=0.90. topic_id is optional and only accepted when the existing read model supplies the same real stable ID. Legacy catalogues expose names, so no invented topic ID is generated. Academic-year metadata unavailable in the existing projection is labelled unspecified.

Blocks: source extract, teaching explanation, definition, example, objectives, misconception, recall with optional reveal answer; structured table, ordered flowchart/mindmap nodes with textual alternative; owned raster image/alt/caption. Imported HTML, SVG, executable scripts and unsafe URL schemes are rejected. Markdown is escaped; imported links render as labels and remote images as textual alternatives. Source navigation is generated by Flask. Formula V1 uses readable text/Unicode or owned raster plus text alternative, without a math CDN.

Transport: UTF-8 JSON <=2MB, or ZIP <=25MB containing module.json and assets/*.png/jpg/jpeg/webp. Canonical importer does not accept PPTX, raw PDFs or prototype HTML. ZIP <=550 entries, <=30MB declared expansion, <=4MB/member, ratio <=150; raster <=2MB/image, <=16M pixels, total <=20MB. Deflate decoding is explicitly capped to declared size+1, with EOF/tail/CRC checks; lying size headers are rejected before large expansion. No paths are extracted. Absolute paths, traversal, symlinks, encrypted archives, unsupported compression, duplicate IDs/keys and unsupported fields fail validation. Sources are <=20MB, <=500 PDF pages. Asset type is checked against image bytes.

Workflow: POST /learning/import validates fully before storage; stages one immutable artifact transaction. GET /learning/staged/<id>/<revision> is an explicit preview. POST .../publish revalidates the live source and mapping before activation. Previously published revisions remain immutable/readable. Changed/reintroduced questions must increment their stable question revision, including historical removed questions. Any duplicate revision with changed content/assets conflicts; identical staging is idempotent.

Storage: only `learning_studio.sqlite3`, separate SQLite application_id 0x414C5331/user_version1, transactional explicit initialization. Foreign/shared/unknown databases and symlink paths are rejected. Read-only GETs never initialize storage. No academic migration or personal Notes/Obsidian writes.

Pilot adapter: `pilot.convert_pilot` validates original PDF, recorded text/image hashes and question locators before deterministic conversion; keeps course mapping null and all semantic pages needing review. The attached V3 archive fails its original-PDF hash gate and is not imported/published:
